# Room Android 实现规格

本文描述 Room Android 客户端的实现边界、模块划分、接口对接和页面要求。页面流转和状态流转见 `docs/客户端逻辑设计.md`，后端接口以 `room-api/docs/接口文档.md` 为准。

## 项目配置

- Android 单模块项目，模块名 `app`。
- 包名和 namespace：`love.moonc.room`。
- `minSdk = 26`。
- 以 Android Studio `Empty Activity` Compose 工程为基础继续实现。
- Gradle 继续使用 Version Catalog：`gradle/libs.versions.toml`。
- `compileSdk = 37`，`targetSdk = 36`。
- 语言：Kotlin。
- UI：Jetpack Compose + Material 3。
- 架构：Compose + ViewModel + StateFlow + 手写轻量 `AppContainer`。
- 网络：Retrofit + OkHttp + kotlinx.serialization。
- 图片加载：Coil Compose。
- 本地存储：DataStore Preferences。
- WebSocket：OkHttp WebSocket。
- 语音：声网 RTC Android SDK。
- 导航：Navigation Compose。
- 当前构建版本：Gradle `9.7.0`、Android Gradle Plugin `9.3.1`、Kotlin `2.4.0`、Compose BOM `2026.06.00`，版本集中维护在 `gradle/libs.versions.toml` 和 `gradle/wrapper/gradle-wrapper.properties`。
- 后端地址写在 `core/network/NetworkConfig.kt`。
- 默认后端地址：`https://room.moonc.love/`。
- 本地联调地址保留为 `http://192.168.110.143:8080/`，在 `NetworkConfig.kt` 中以注释形式维护，需要联调时手动切换。
- WebSocket 地址从 HTTP base url 派生，例如 `https://room.moonc.love/` 派生为 `wss://room.moonc.love/api/v1/app/ws/rooms/{roomId}`。
- App 启动先请求 `GET /api/v1/app/version/latest`，且该步骤是严格门控：仅当请求成功、业务 `code == 200` 且不存在更高 `version_code` 时，才创建会话恢复逻辑并请求 `/users/me`。服务端返回更高版本时必须完成升级；更新检查请求或业务失败时停留检查更新失败页，仅允许重试，不能进入登录或业务页面。
- 升级 APK 下载到应用缓存目录后，通过 FileProvider 调起系统安装器。APK 签名由 Android 系统用于识别合法更新。
- OkHttpClient 配置 WebSocket ping interval 为 10 秒；后端 WebSocket 也会每 30 秒发送一次 ping。

- AndroidX Core、Activity Compose、Lifecycle Runtime Compose、Lifecycle ViewModel Compose。

## 网络规则

后端 HTTP 响应统一为：

```json
{
  "code": 200,
  "message": "成功",
  "data": {}
}
```

客户端规则：

- HTTP 状态码不是主要判断依据，业务成功以 `code == 200` 为准。
- 业务失败优先展示后端 `message`。
- `code == 401` 或 `/users/me` 恢复失败时清空 token 并回登录页。普通 HTTP API 的 `code == 401` 由 `ApiResponseExt.requireData/requireSuccess` 统一触发 `SessionExpiredCenter`，再由 `RoomApp` 统一提示并退出登录。
- 网络失败展示通用网络错误。
- JSON 使用 `ignoreUnknownKeys = true`。
- 请求和响应字段按后端 snake_case 命名，Kotlin 侧使用 kotlinx.serialization 显式映射。
- 时间字段先按 ISO 8601 字符串保存，UI 展示时再格式化。

## Token

- DataStore Preferences 文件名：`room_settings`。
- token key：`auth_token`。
- 邮箱验证码登录成功后保存 token；未注册邮箱由后端自动注册并登录。
- 退出登录时清空 token。
- OkHttp Interceptor 自动追加 `Authorization: Bearer {token}`。
- App 启动时如果本地有 token，必须请求 `/api/v1/app/users/me` 恢复登录态。

## HTTP API

Retrofit API 覆盖以下接口：

| 功能 | 方法 | 路径 | 鉴权 |
| --- | --- | --- | --- |
| 发送登录验证码 | POST | `/api/v1/app/auth/email-code` | 否 |
| 邮箱验证码登录 | POST | `/api/v1/app/auth/email-login` | 否 |
| 当前用户 | GET | `/api/v1/app/users/me` | 是 |
| 更新昵称 | PATCH | `/api/v1/app/users/me` | 是 |
| 上传图片 | POST multipart | `/api/v1/app/uploads/image` | 是 |
| 房间列表 | GET | `/api/v1/app/rooms?page=1&page_size=20` | 是 |
| 创建房间 | POST | `/api/v1/app/rooms` | 是 |
| 房间详情 | GET | `/api/v1/app/rooms/:room_id` | 是 |
| 声网 RTC Token | GET | `/api/v1/app/rooms/:room_id/rtc-token` | 是 |
| 进入房间 | POST | `/api/v1/app/rooms/:room_id/join` | 是 |
| 离开房间 | POST | `/api/v1/app/rooms/:room_id/leave` | 是 |
| 更新麦克风 | PATCH | `/api/v1/app/rooms/:room_id/mic` | 是 |
| 历史消息 | GET | `/api/v1/app/rooms/:room_id/messages?limit=20&before_id=100` | 是 |
| 发送消息 | POST | `/api/v1/app/rooms/:room_id/messages` | 是 |

图片上传 multipart 字段名固定为 `file`，返回字段为 `url`。

## 数据模型

客户端模型与后端对象一一对应。

### User

- `id`
- `email`
- `nickname`
- `avatar_url`
- `current_room_id`
- `created_at`
- `updated_at`

`current_room_id` 为 `null` 表示用户当前不在房间内。

### Room

- `id`
- `name`
- `owner_id`
- `current_members`
- `max_members`
- `created_at`

房主以 `owner_id` 为准。

### RoomMember

- `user_id`
- `nickname`
- `avatar_url`
- `is_owner`
- `mic_status`
- `joined_at`

`mic_status` 取值为 `on` 或 `off`。

### Message

- `id`
- `room_id`
- `sender_id`
- `sender_nickname`
- `sender_avatar_url`
- `type`
- `content`
- `created_at`

第一版消息类型为 `text`。

### 主要请求

- 邮箱验证码登录：`email`、`email_code`。
- 创建房间：`max_members`，只能是 `2` 或 `8`。
- 更新麦克风：`mic_status`，只能是 `on` 或 `off`。
- 发送消息：`content`。

## WebSocket

连接：

- 路径：`/api/v1/app/ws/rooms/:room_id`。
- 请求头：`Authorization: Bearer {token}`。
- 进入房间成功后再建立 WebSocket。
- 主动离开时先调用离开接口，再主动关闭 WebSocket；主动关闭不展示断线提示。
- WebSocket 异常断开时，按后端语义视为已离开房间，回主界面首页并提示“连接已断开，已离开房间”。
- WebSocket 握手或连接失败的 HTTP 响应为 401 时，按登录过期处理：清空 token，回登录页，并提示“登录已过期，请重新登录”。
- 断线提示通过 `MessageCenter` 发送，由 app 级 `CenterMessageHost` 居中展示，页面不需要单独传参承接。

## 声网语音

- App ID 定义在 `core/network/NetworkConfig.kt`；App ID 可放客户端，App Certificate 只能保存在服务端。
- 频道名为 `room-{roomId}`，当前用户 ID 作为声网 uid。
- 房间 HTTP 详情和消息加载成功后加入频道，默认关闭本地麦克风并订阅远端音频。
- 点击自己的成员槽位开麦时请求 `RECORD_AUDIO` 权限；后端 `PATCH /rooms/:room_id/mic` 成功后同步声网本地麦克风状态。
- 主动离开、WebSocket 断线或鉴权失效时退出声网频道。
- 加入频道前请求 `GET /api/v1/app/rooms/:room_id/rtc-token`；后端确认用户仍是房间成员后，签发仅适用于该频道和 uid 的 1 小时 Token。`onTokenPrivilegeWillExpire` 或 `onRequestToken` 时自动续签。App Certificate 只能保存在服务端。

## WebSocket 事件

事件外层：

- `type`
- `room_id`
- `data`

事件类型：

| type | data |
| --- | --- |
| `member.joined` | `member`、`current_members` |
| `member.left` | `user_id`、`current_members` |
| `room.owner_changed` | `owner_id`、`members` |
| `message.created` | `message` |
| `member.mic_updated` | `member` |

事件处理：

- `member.joined`：按 `user_id` 追加或覆盖成员，并更新人数。
- `member.left`：按 `user_id` 删除成员，并更新人数。
- `room.owner_changed`：更新 `owner_id`，事件携带 `members` 时覆盖成员列表。
- `message.created`：按消息 `id` 去重后追加。
- `member.mic_updated`：按 `user_id` 替换成员。

## 导航

页面路由：

- `splash`
- `login`
- `main/home`
- `main/me`
- `profile/edit`
- `rooms/create`
- `rooms/{roomId}`

登录后的主界面使用底部 Tabbar：

- `首页`：房间列表。
- `我的`：用户资料。

底部 Tabbar 切换使用 `popUpTo(Routes.Home)` 配合 `saveState`、`launchSingleTop` 和 `restoreState`，重复点击或来回切换 Tab 不应产生重复返回栈。

启动逻辑：

- 首先请求 `/app-version/latest`；更新检查失败停留错误页并重试，不恢复会话。
- 更新检查成功且存在更高版本：进入强制升级流程。
- 更新检查成功且没有更高版本后：无 token 时进入登录页；有 token 时请求 `/users/me`。
- `/users/me` 成功且 `current_room_id == null`：进入主界面首页。
- `/users/me` 成功且 `current_room_id != null`：进入房间详情。
- `/users/me` 失败：清空 token，进入登录页。
- 邮箱验证码登录成功后直接使用接口返回的 `user` 导航，不额外请求 `/users/me`。

## ViewModel

### AuthViewModel

负责：

- 登录。
- 发送登录验证码。
- 邮箱验证码登录。
- 保存 token。

本地校验：

- 昵称 trim 后 1-8 个字符。
- 邮箱非空且符合基本邮箱格式。
- 验证码非空。

### ProfileViewModel

负责：

- 加载当前用户。
- 更新昵称。
- 保存资料；点击保存时先按需上传图片，再通过 `PATCH /users/me` 同时提交昵称和头像 URL。
- 退出登录。

### RoomListViewModel

负责：

- 加载房间第一页。
- 下拉刷新。
- 加载更多。
- 进入房间。

分页：

- 默认 `page = 1`，`page_size = 20`。
- `hasMore` 根据已加载数量和后端 `total` 判断。

### RoomDetailViewModel

负责：

- 加载房间详情。
- 加载历史消息。
- 建立和关闭 WebSocket。
- 发送文字消息。
- 加载更早消息。
- 更新麦克风状态。
- 主动离开房间。
- 主动离开期间维护 `leaving` 状态，防止重复请求。
- 处理 WebSocket 事件。
- 区分 WebSocket 401 和普通异常断开。

进入房间详情顺序：

1. 请求房间详情。
2. 请求历史消息。
3. 加入声网语音频道（失败仅提示，不影响房间和 WebSocket）。
4. 建立 WebSocket。

消息规则：

- 输入 trim 后 1-50 字才允许发送。
- 发送成功后清空输入框。
- 消息列表等待 `message.created` 广播追加。
- 加载更早消息使用当前最小 message id 作为 `before_id`。

## 页面规格

UI 风格：

- 使用简单默认 Material 3 风格。
- 跟随系统浅色/深色主题。
- 时间显示格式为年月日时分秒。
- 错误和短提示统一通过 app 级 `MessageCenter` + `CenterMessageHost` 居中展示。
- 页面不重复渲染 `ErrorText(state.message)`；ViewModel 在需要时调用 `MessageCenter.show(...)`。

### 登录页

- 登录页不显示顶部栏，不显示左上角 Room 文字。
- 正文只展示放大加粗的 Room 品牌标题。
- 邮箱输入。
- 发送验证码 TextButton，与邮箱输入框垂直居中对齐；发送中只禁用自身并显示“发送中”。
- 验证码输入。
- 登录按钮。
- 不提供注册账号入口。
- 不提供忘记密码/重置密码入口。

未注册邮箱由后端在邮箱验证码登录成功时自动注册并登录。

### 首页

- 顶部栏标题为空。
- 右上角仅保留创建房间入口，不提供右上角刷新按钮。
- 房间列表。
- 下拉刷新；有列表和空状态时都可以下拉刷新。
- 加载更多。
- 空状态。
- 断开连接全局居中提示。
- 底部 Tabbar，当前选中 `首页`。

房间项展示房间名、当前人数、最大人数和右侧进入状态；不展示创建时间。

右侧状态文案为 `进入`、`进入中` 或 `满员`，相对整个房间卡片垂直居中。

进入房间使用独立的 `joiningRoomId` 状态，不复用列表刷新 `loading`，避免触发或卡住下拉刷新 loading。

当 `current_members >= max_members` 时，进入状态展示为满员且不可点击；如果仍发起进入请求，以后端错误为准。

点击创建房间进入创建房间页。

空状态展示“暂无房间”，仍支持下拉刷新。

WebSocket 异常断开返回首页时，通过全局居中提示展示“连接已断开，已离开房间”。

该提示由 app 级消息宿主展示；首页刷新产生的网络错误同样走 `MessageCenter`，页面内不重复写 `ErrorText(state.message)`。

### 创建房间页

- 不显示顶部栏，也不显示左上角返回箭头。
- `2人房` 选项。
- `8人房` 选项。
- 创建按钮放在页面底部。

默认选中 `8人房`。创建成功后进入房间详情页。
### 我的

- 顶部栏标题为空。
- 个人资料卡片展示头像、昵称和邮箱地址。头像 URL 存在但图片尚未加载完成时，头像圆框内显示加载中；加载失败或 URL 为空时显示默认头像。
- 邮箱只展示地址本身，不显示“邮箱”标签。
- 点击个人资料卡片进入编辑资料页。
- 不展示单独的编辑资料按钮。
- 退出登录按钮放在页面底部区域。
- 底部 Tabbar，当前选中 `我的`。

### 编辑资料页

- 不显示顶部栏，也不显示左上角返回箭头。
- 头像圆框。
- 点击头像圆框直接打开系统相册。
- 不展示“选择头像”或“更换头像”文字。
- 昵称输入。
- 保存按钮放在页面底部。

编辑资料页从 `我的` 进入，不显示底部 Tabbar。保存资料成功后更新全局用户状态并返回 `我的` 页。

选择头像后只做本地预览，不立即调用上传接口。点击保存时如存在新头像，先调用 `POST /uploads/image` 获取 `url`，否则继续使用当前头像 URL；随后通过 `PATCH /users/me` 同时提交 `nickname` 和 `avatar_url`。

### 房间详情页

- 不显示顶部栏和右上角离开按钮。
- 左滑页面触发退出房间二次确认。
- 确认离开后调用 `POST /api/v1/app/rooms/:room_id/leave`。
- 离开请求未完成时确认弹窗保持显示，确认按钮文案为“离开中”，取消、返回、点外部关闭和重复确认均禁用。请求成功后返回首页；请求失败则留在房间并通过 `MessageCenter` 展示错误。
- 顶部展示房间标题，使用后端返回的 `room.name`。
- 中间区域展示消息列表，并保留“加载更早消息”入口。
- 消息输入框和发送按钮在同一行，垂直居中对齐。
- 发送按钮使用 Material 3 `FilledIconButton`，仅展示发送图标；空输入时禁用。
- 底部展示成员头像槽位，槽位数量按 `max_members` 固定渲染。
- 已有人槽位显示成员头像和昵称；无人槽位显示“空位”占位样式。
- 成员麦克风状态以头像右下角覆盖角标展示。
- 当前用户点击自己的头像槽位可切换麦克风状态；不再使用单独的“我的麦克风” Switch。

房间详情页不显示底部 Tabbar，也不提供用户资料入口。

消息展示：

- 第一版消息按 `发送者昵称: 内容` 展示。
- 空消息列表展示“暂无消息”。
- 显示文字内容。

## 头像文件处理

- 头像来源支持相册选择。
- 点击头像圆框直接打开系统相册，不弹出来源选择菜单。
- 相册可使用 `PickVisualMedia` 或 `GetContent("image/*")`。
- 文件类型限制为 JPEG、PNG、WebP。
- 本地限制文件大小不超过 2MB。
- MIME 类型优先使用 ContentResolver，fallback 为 `image/jpeg`。
- 点击保存后，如果存在新头像，先上传到 `POST /api/v1/app/uploads/image`。
- 上传接口返回 `url`；随后通过 `PATCH /api/v1/app/users/me` 同时提交 `nickname` 和 `avatar_url` 更新当前用户。
- `PATCH /api/v1/app/users/me` 成功后返回 `我的` 页。

## AndroidManifest

权限：

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
```

`application` 使用 `.RoomApplication`，并配置 `usesCleartextTraffic="true"`，以支持当前局域网 HTTP 后端地址。

Debug 明文 HTTP 访问局域网后端地址需要允许 cleartext。
