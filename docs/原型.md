# Room Android 原型

## 登录页

登录页顶部栏标题为空，不显示左上角 Room 文字；原型中的 Room 为正文品牌标题。登录只使用邮箱验证码；未注册邮箱由后端自动注册后登录。

```txt
┌──────────────────────────────────────┐
│                                      │
│                                      │
│                Room                  │
│                                      │
│  ┌────────────────────┐ ┌─────────┐  │
│  │ 邮箱               │ │发送验证码│  │
│  └────────────────────┘ └─────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 验证码                         │  │
│  └────────────────────────────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │              登录              │  │
│  └────────────────────────────────┘  │
│                                      │
└──────────────────────────────────────┘
```

## 首页

```txt
┌──────────────────────────────────────┐
│                                  +   │
├──────────────────────────────────────┤
│  ┌────────────────────────────────┐  │
│  │ Neo 的房间                 进入 │  │
│  │ 1 / 8 人                      │  │
│  └────────────────────────────────┘  │
│  ┌────────────────────────────────┐  │
│  │ 满员房间                  满员 │  │
│  │ 8 / 8 人                      │  │
│  └────────────────────────────────┘  │
│                                      │
├──────────────────────────────────────┤
│        首页                  我的     │
└──────────────────────────────────────┘
```

首页右上角只保留创建房间入口。房间列表和空状态都通过下拉刷新更新，不展示右上角刷新按钮，也不展示房间创建时间。

空状态：

```txt
┌──────────────────────────────────────┐
│                                  +   │
├──────────────────────────────────────┤
│                                      │
│              暂无房间                 │
│                                      │
├──────────────────────────────────────┤
│        首页                  我的     │
└──────────────────────────────────────┘
```

## 我的

```txt
┌──────────────────────────────────────┐
│                                      │
├──────────────────────────────────────┤
│  ┌────────────────────────────────┐  │
│  │              ◯                 │  │
│  │             Neo                │  │
│  │        neo@example.com         │  │
│  └────────────────────────────────┘  │
│                                      │
│                                      │
│                                      │
│            退出登录                  │
├──────────────────────────────────────┤
│        首页                  我的     │
└──────────────────────────────────────┘
```

点击个人资料卡片进入编辑资料页；不展示单独的“编辑资料”按钮。邮箱只显示地址本身。

## 编辑资料页

```txt
┌──────────────────────────────────────┐
│                                      │
├──────────────────────────────────────┤
│                                      │
│                 ◯                    │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 昵称                           │  │
│  └────────────────────────────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │              保存              │  │
│  └────────────────────────────────┘  │
│                                      │
└──────────────────────────────────────┘
```

点击头像圆框直接打开系统相册。上传头像成功后展示服务端返回的头像地址，不自动返回；点击保存成功后返回“我的”页。
