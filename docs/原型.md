# Room Android 原型

## 登录页

登录页顶部栏标题为空，不显示左上角 Room 文字；原型中的 Room 为正文品牌标题。登录只使用邮箱验证码；未注册邮箱由后端自动注册后登录。

```txt
┌──────────────────────────────────────┐
│                                      │
│                                      │
│                 Room                 │
│            邮箱验证码登录             │
│                                      │
│  ┌────────────────────┐ ┌─────────┐  │
│  │ 邮箱               │ │发送验证码│  │
│  └────────────────────┘ └─────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 验证码                         │  │
│  └────────────────────────────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │              登录              │  │
│  └────────────────────────────────┘  │
│                                      │
└──────────────────────────────────────┘
```

## 首页

```txt
┌──────────────────────────────────────┐
│  首页                         +  ↻   │
├──────────────────────────────────────┤
│  ┌────────────────────────────────┐  │
│  │ Neo 的房间                     │  │
│  │ 1 / 8 人               进入    │  │
│  │ 2026-08-18 20:10:00            │  │
│  └────────────────────────────────┘  │
│                                      │
├──────────────────────────────────────┤
│        首页                  我的     │
└──────────────────────────────────────┘
```

断开连接提示：

```txt
┌──────────────────────────────────────┐
│                                      │
│        连接已断开，已离开房间          │
│                                      │
└──────────────────────────────────────┘
```
