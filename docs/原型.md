# Room Android 原型

## 登录页

登录页不显示顶部栏；原型中的 Room 为正文品牌标题。登录只使用邮箱验证码；未注册邮箱由后端自动注册后登录。

```txt
┌──────────────────────────────────────┐
│                                      │
│                                      │
│                Room                  │
│                                      │
│  ┌────────────────────┐ ┌─────────┐  │
│  │ 邮箱               │ │发送验证码│  │
│  └────────────────────┘ └─────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 验证码                         │  │
│  └────────────────────────────────┘  │
│                                      │
│  ┌────────────────────────────────┐  │
│  │              登录              │  │
│  └────────────────────────────────┘  │
│                                      │
└──────────────────────────────────────┘
```

## 首页

```txt
┌──────────────────────────────────────┐
│                                  +   │
├──────────────────────────────────────┤
│  ┌────────────────────────────────┐  │
│  │ Neo 的房间                 进入 │  │
│  │ 1 / 8 人                      │  │
│  └────────────────────────────────┘  │
│  ┌────────────────────────────────┐  │
│  │ 满员房间                  满员 │  │
│  │ 8 / 8 人                      │  │
│  └────────────────────────────────┘  │
│                                      │
├──────────────────────────────────────┤
│        首页                  我的     │
└──────────────────────────────────────┘
```

首页右上角只保留创建房间入口。房间列表和空状态都通过下拉刷新更新，不展示右上角刷新按钮，也不展示房间创建时间。

空状态：

```txt
┌──────────────────────────────────────┐
│                                  +   │
├──────────────────────────────────────┤
│                                      │
│              暂无房间                 │
│                                      │
├──────────────────────────────────────┤
│        首页                  我的     │
└──────────────────────────────────────┘
```

## 我的

```txt
┌──────────────────────────────────────┐
│                                      │
├──────────────────────────────────────┤
│  ┌────────────────────────────────┐  │
│  │          ◯ / loading           │  │
│  │             Neo                │  │
│  │        neo@example.com         │  │
│  └────────────────────────────────┘  │
│                                      │
│                                      │
│                                      │
│            退出登录                  │
├──────────────────────────────────────┤
│        首页                  我的     │
└──────────────────────────────────────┘
```

点击个人资料卡片进入编辑资料页；不展示单独的“编辑资料”按钮。邮箱只显示地址本身。

## 编辑资料页

```txt
┌──────────────────────────────────────┐
│                                      │
├──────────────────────────────────────┤
│                                      │
│                 ◯                    │
│                                      │
│  ┌────────────────────────────────┐  │
│  │ 昵称                           │  │
│  └────────────────────────────────┘  │
│                                      │
│                                      │
│                                      │
│  ┌────────────────────────────────┐  │
│  │              保存              │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

点击头像圆框直接打开系统相册。选择头像后只做本地预览；点击保存时先上传图片获得 url，再通过更新资料接口提交昵称和 avatar_url，成功后返回“我的”页。保存按钮位于页面底部。

## 房间详情页

```txt
┌──────────────────────────────────────┐
│                                      │
├──────────────────────────────────────┤
│  Neo 的房间                          │
│                                      │
│  Neo: 大家好                         │
│  Mia: 哈喽                           │
│                                      │
│                                      │
│  ┌──────────────────────┐┌────────┐ │
│  │ 输入消息             ││发送    │ │
│  └──────────────────────┘└────────┘ │
│                                      │
│  ◯◟  ◯◝  ◯   ◯   ◯   ◯   ◯   ◯       │
│ Neo  Mia  空位 空位 空位 空位 空位 空位 │
└──────────────────────────────────────┘
```

房间详情页底部头像槽位按房间容量展示；空位展示占位样式，麦克风状态以头像右下角角标展示。输入框和发送按钮保持垂直居中对齐。

左滑页面时弹出确认框：取消留在房间；确认后离开房间并返回首页。
